# biocolorant-ML
## Requirements
Python 3.9, RDKit, Mordred, scikit-learn, SHAP, pandas, numpy, matplotlib, openpyxl
## Workflow
1. Descriptor calculation: Mordred descriptors and SMILES validation.
2. Data splitting: training/test set preparation.
3. Modeling and SHAP analysis: DNN-QSPR and MLR models.
4. Virtual screening: high-throughput screening and candidate selection.
5. External validation: prediction for eight bio-based colorant standards.
6. TD-DFT comparison: DNN vs. TD-DFT λmax comparison.
Run the scripts following this order.
